# 电视哔哩哔哩使用时长提醒应用设计

> 2026-11-08 用户修订：每次电视关机或待机后清零，不要求先超时或弹出提醒；重新开机后从 0 开始。退出客户端、关闭提醒开关及同次开机内服务重启仍保留本轮进度，跨天清零不变。界面显示“本轮已看”。本修订覆盖下文原始设计中“息屏暂停并保留当天累计”的表述，实施记录见 `../plans/2026-11-08-reset-after-power-off.md`。

## 目标与已确认需求

开发可安装到 REDMI 电视上的独立 Android 应用。目标电视运行小米澎湃 OS 3，具体 Android 版本和权限入口需要真机核验。

- 监测哔哩哔哩前台使用时间，当天累计；退出后暂停，重新进入继续，次日清零。
- 应用自己的设置页面提供启用开关，首次安装默认开启；弹窗中不展示开关或时间设置。
- 设置页面提供“开始提醒（分钟）”，默认 13；“开始确认提醒（分钟）”，默认 15。
- 普通提醒显示“时间快到了哦!”，显示 5 秒倒计时，结束自动关闭。
- 确认提醒显示“时间到了哦!”，必须使用遥控器操作【确认】才能在继续观看时关闭。
- 同时最多显示一个弹窗；已有弹窗未关闭时跳过新提醒，不排队补弹。

## 推荐实现与替代方案

推荐 Kotlin 原生 Android 应用，使用无障碍服务识别目标应用前台状态，使用无障碍悬浮窗展示提醒。首次使用引导家长启用系统无障碍服务，并选择本机实际安装的哔哩哔哩客户端，避免硬编码单一版本包名。

替代方案为使用情况访问权限、前台服务与普通悬浮窗，需额外处理轮询、权限和后台限制。先验证推荐方案；如果电视不开放必要能力，再根据真机结果评估替代方案。

参考 Android 官方文档：

- https://developer.android.com/reference/android/accessibilityservice/AccessibilityService
- https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_ACCESSIBILITY_OVERLAY

## 设置页面

支持电视遥控器方向键、确定键和返回键，焦点清晰可见。

1. 启用提醒：默认开启，保存用户选择，应用重启后不恢复成默认值。
2. 开始提醒（分钟）：默认 13，正整数。
3. 开始确认提醒（分钟）：默认 15，正整数，必须大于开始提醒分钟数。
4. 今日累计时长：只读展示。
5. 目标应用选择与无障碍服务状态：供首次配置和排查使用。

分钟设置编辑后通过【保存】生效；无效值显示说明并禁止保存。启用开关立即生效。配置存储在本机，不需要账户或后端。

## 计时与提醒规则

以下是根据已确认需求补充的实现约定，供实现前检查。

- 只在提醒开关开启、屏幕处于可交互状态且目标应用在前台时累计。浏览首页、选视频和暂停播放均计时，不检测实际视频播放状态。
- 退出目标应用或息屏时暂停，撤下当前提醒；返回后接着累计。
- 关闭开关立即暂停计时并撤下提醒，保留当天累计。关闭期间不计时，重新开启后继续。
- 按电视本地日期划分“当天”，跨午夜清零；连续观看跨午夜时，以午夜为边界计算新一天的时长。
- 使用单调时钟计算运行中的时长，并持久化日期和累计进度。服务终止期间不凭墙上时钟补计；每 5 秒和暂停、开关切换等状态变化时提交保存。异步落盘期间突然断电或强杀可能损失最近的进度，不保证严格的最大损失时长。
- 普通提醒从开始提醒阈值起，在每个累计整分钟触发，直到确认提醒阈值之前。默认在累计 13:00、14:00 触发。
- 确认提醒从确认提醒阈值起，在每个累计整分钟触发。默认在累计 15:00、16:00、17:00 等触发。
- 提醒显示期间仍累计目标应用的使用时间，不能把自身悬浮窗误判为离开目标应用。
- 确认提醒默认聚焦【确认】，遥控器确定键关闭；返回键不能作为确认关闭。主页键离开目标应用或息屏时可以撤下弹窗，同时暂停计时。
- 已有弹窗时跳过当前触发点。确认关闭后等下一个累计整分钟，不立即补弹。
- 已超过确认阈值时重新进入目标应用或重新启用开关，立即显示一次确认提醒，避免反复切出绕过提醒。普通提醒阶段重新进入时等下一个整分钟。
- 保存新分钟设置后撤下旧提醒并按新阈值判断；已经达到新确认阈值则在目标应用下次处于前台时立即显示确认提醒，否则等待后续整分钟，不补发历史提醒。
- 提醒不主动控制哔哩哔哩播放。视频在弹窗期间是否继续播放，由目标客户端的窗口焦点处理决定，需真机观察。

## 实现边界

- 计时状态机：负责累计、跨日、阈值、暂停恢复及避免重复触发，独立于 Android 界面，便于测试。
- 监测服务：识别目标应用、交互状态和本应用悬浮窗，将状态变化交给计时状态机。
- 提醒窗口：负责文字、倒计时、遥控器焦点和确认操作，只允许单实例。
- 设置与本地存储：保存启用状态、两个分钟阈值、目标应用和当天累计进度。
